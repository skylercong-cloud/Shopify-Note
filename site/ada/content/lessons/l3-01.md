# L3-01 打开配件弹窗后，焦点应该去哪儿？

> **本课目标：** 验证弹窗的初始焦点、背景隔离、退出和恢复焦点。

## 打开、操作、关闭

Dreame 德国站的配件浮层打开后，移动读屏仍可能滑到下面的商品页。模态弹窗需要分别处理三个阶段。

1. **打开。** 焦点进入具名弹窗。短配件弹窗可以先聚焦关闭按钮。长内容可以先聚焦带 `tabindex="-1"` 的标题，让用户从头读。
2. **操作。** Tab 与 Shift+Tab 都在弹窗内走，背景暂时与操作隔离。用手机读屏再验证浏览路径，数量输入框和加减按钮可以分别到达。
3. **关闭。** 通过 Escape 或明确的关闭按钮离开。通常回到触发点。如果触发卡片已被移除，把焦点放到下一个合适的卡片或列表入口。

## 原生弹窗能做什么

```html
<button id="open-accessory" type="button">查看配件</button>

<dialog id="accessory-dialog" aria-labelledby="accessory-title">
  <h2 id="accessory-title">配件详情</h2>
  <button id="close-accessory" type="button" autofocus>
    关闭配件详情
  </button>
  <label for="accessory-quantity">配件数量</label>
  <input id="accessory-quantity" type="number" min="1" value="1">
</dialog>

<script>
  const opener = document.querySelector('#open-accessory');
  const dialog = document.querySelector('#accessory-dialog');
  const closeButton = document.querySelector('#close-accessory');

  opener.addEventListener('click', () => dialog.showModal());
  closeButton.addEventListener('click', () => dialog.close());
</script>
```

`showModal()` 是原生 `<dialog>` 对应的 JavaScript 方法。它打开模态弹窗，让背景处于不可交互状态，并运行浏览器的初始聚焦规则。`autofocus` 用来显式指定初始目标。省略时，浏览器仍会按自身规则选择焦点。用键盘打开后，分别测试 Escape 和关闭按钮，再验证焦点恢复。[HTML dialog](https://html.spec.whatwg.org/multipage/interactive-elements.html#the-dialog-element) · [W3C 模态弹窗模式](https://www.w3.org/WAI/ARIA/apg/patterns/dialog-modal/)

## autofocus 必须用在 button 或 dialog 里吗？

`autofocus` 是全局 HTML 属性。普通页面可以给搜索框加 `autofocus`，让浏览器在页面载入时尝试聚焦。放在原生 `dialog` 内时，浏览器在**弹窗显示时**考虑它。它可以标在按钮、输入框等能接收焦点的元素上。每个弹窗选一个初始目标即可。[HTML autofocus 规则](https://html.spec.whatwg.org/multipage/interaction.html#the-autofocus-attribute)

如果希望先读长说明，就在顶部标题上同时写两个属性，原来的关闭按钮可以去掉 `autofocus`：

```html
<dialog id="accessory-dialog" aria-labelledby="accessory-title">
  <h2 id="accessory-title" tabindex="-1" autofocus>配件说明</h2>
  <p>请先确认配件型号和适用范围。</p>
  <form method="dialog">
    <button type="submit">关闭</button>
  </form>
</dialog>
```

在打开按钮的处理里调用 `document.querySelector('#accessory-dialog').showModal()`。此时 `tabindex="-1"` 让标题可以接收焦点，`autofocus` 告诉浏览器把初始焦点给它。也可以省去 `autofocus`，在 `showModal()` 后显式对标题调用 `.focus()`。

如果旧主题用 `div` 做弹窗，`role="dialog"` 和 `aria-modal="true"` 用于表达语义和状态。实际打开、背景隔离、初始聚焦与退出仍由组件实现。初始焦点可以在自定义弹窗显示后调用 `目标元素.focus()`。[W3C 无键盘陷阱](https://www.w3.org/WAI/WCAG22/Understanding/no-keyboard-trap.html) · [常用属性速查](?lesson=ref-02)

## 练习与验收

用户在弹窗里移除了触发它的配件卡片。列表里还有其他配件、列表已清空，这两种情况下关闭后分别应聚焦哪里？从那里继续完成用户任务，验证焦点位置是否合理。
