# L4-01 浅灰字能看见，为什么对比度还是不够？

> **本课目标：** 检查文字和控件对比度，并让状态有颜色之外的视觉线索。

## 对比度量的是文字和实际背景

Dreame 德国站的首页轮播也涉及字体颜色与背景。普通文字的 AA 阈值是 4.5:1。大号文字是 3:1，通常至少 24 CSS px，或约 18.67 CSS px 且加粗。识别控件或状态所需的非文本视觉信息，按适用规则与相邻颜色至少达到 3:1。

| 白底上的颜色 | 大致对比度 |
| --- | --- |
| `#999` | 2.85:1 |
| `#777` | 4.48:1 |
| `#666` | 5.74:1 |

普通文字的 4.48:1 仍低于 4.5:1。用浏览器查实际颜色，两处背景不同就分开量。[WCAG 文字对比](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html) · [非文本对比](https://www.w3.org/WAI/WCAG22/Understanding/non-text-contrast.html)

## 轮播、角标和选中状态

轮播第一张背景深，下一张可能让浅色商品正好出现在白字下面。桌面与移动端裁切不同，逐张检查文字背后的实际区域。可使用更可靠的底板、遮罩或独立的文案区域。[Chrome DevTools 对比度检查](https://developer.chrome.com/docs/devtools/accessibility/contrast)

Tab 的文字都清楚，颜色变化仍可能无法说明哪个面板选中。可以从同一个 `aria-selected` 状态画出一条下划线：

```css
.product-tab[aria-selected="true"] {
  text-decoration: underline;
  text-decoration-thickness: 0.18em;
  text-underline-offset: 0.3em;
}
```

下划线标识选中状态，`aria-selected` 表达同一状态，焦点轮廓指示当前能操作哪一项。手动激活的 Tab 中，焦点和选中可能分开。[WCAG 颜色使用](https://www.w3.org/WAI/WCAG22/Understanding/use-of-color.html)

## 练习与验收

白底用 `#999` 显示原价，仅靠红色区分现价。先调整颜色是否读得清，再加「原价」「促销价」等可辨识的信息，在实际商品卡片上量对比度并用读屏检查含义。
