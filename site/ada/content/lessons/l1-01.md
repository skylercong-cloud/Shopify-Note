# L1-01 为什么读屏只说「按钮」？

> **本课目标：** 知道浏览器从哪里获得控件名称，并为图标按钮、输入框与弹窗命名。

## 名称回答「它做什么」

商品卡片上有一个 ×。如果读屏只报「按钮」，说明角色已被识别，用户却还需要名称来判断动作。「关闭配件详情，按钮」里，前半句是可访问名称，后半句是角色。

## 从哪里取名称

**按钮有可见文字时，直接取文字。**

```html
<button type="button">加入购物车</button>
```

若给它写上 `aria-label="购买商品"`，这会覆盖从内容得出的名称。语音操作用户可能直接说屏幕上看到的「加入购物车」。确需加上下文时，让可访问名称包含可见文案，比如「加入购物车，Dreame A2」。[WCAG 可见标签包含在名称中](https://www.w3.org/WAI/WCAG22/Understanding/label-in-name.html)

**按钮只有图标时，给操作取名。**

```html
<button type="button" aria-label="关闭配件详情">
  <span aria-hidden="true">×</span>
</button>
```

数量控件的加减号可以叫「增加配件数量」「减少配件数量」。这些名称也随站点语言翻译。

**页面已有合适的文字时，可以用 `aria-labelledby` 引用。**

```html
<dialog aria-labelledby="accessory-title">
  <h2 id="accessory-title">配件详情</h2>
  <button type="button" aria-label="关闭配件详情">
    <span aria-hidden="true">×</span>
  </button>
</dialog>
```

弹窗和关闭按钮分别命名。主题可能重复渲染一个 Section，同一页面里的标题 ID 要唯一。输入框若有单独的可见标签，可以优先用 `<label for="…">`，并对应输入框的 `id`。[W3C 可访问名称指南](https://www.w3.org/WAI/ARIA/apg/practices/names-and-descriptions/) · [表单标签](https://www.w3.org/WAI/tutorials/forms/labels/)

## 练习与验收

两张卡片的链接都叫「查看详情」。如何让它们分别说明是哪个商品，又保留可见文字？

```html
<h2 id="a2-title">Dreame A2</h2>
<a href="/products/a2" aria-labelledby="a2-details a2-title">
  <span id="a2-details">查看详情</span>
</a>
```

用 Chrome DevTools 的 Accessibility 面板查看 Name 和 Role，再让读屏实际读取链接。另一张卡片使用自己的标题和 ID。[Chrome DevTools 无障碍检查](https://developer.chrome.com/docs/devtools/accessibility/reference/)
