# L3-02 展开、选中和按下，怎么表达组件状态？

> **本课目标：** 为折叠区、选项卡和切换按钮选择对应状态。

## 从用户想知道的事选状态

德国站翻新详情视觉上收起后，读屏仍可能访问内容。商品展示的选项卡也曾只靠颜色提示选中。处理时拆开组件的视觉、实际行为和辅助技术状态。

| 问题 | 状态和场景 |
| --- | --- |
| 这块内容展开了吗？ | `aria-expanded`，例如翻新详情、配送说明。 |
| 一组里当前选中哪项？ | `aria-selected`，例如「功能、规格、配件」这组 Tab。 |
| 这个切换按钮的功能开着吗？ | `aria-pressed`，例如作为切换按钮的「仅看有货」。 |

简单折叠可以用 `details` 和 `summary`。旧组件要自定义折叠时，从同一个布尔值更新面板和触发按钮。

```html
<button type="button" id="details-toggle"
        aria-expanded="false" aria-controls="details-panel">
  翻新详情
</button>
<div id="details-panel" hidden>
  <p>商品已完成检测和清洁。</p>
  <a href="/pages/refurbished-policy">查看翻新政策</a>
</div>
<script>
  const toggle = document.querySelector('#details-toggle');
  const panel = document.querySelector('#details-panel');

  toggle.addEventListener('click', () => {
    const expanded = panel.hidden;
    panel.hidden = !expanded;
    toggle.setAttribute('aria-expanded', String(expanded));
  });
</script>
```

收起后用 Tab 检查「查看翻新政策」是否被跳过。仅做透明度动画时，要额外验证焦点与读屏是否仍能访问面板。[W3C 折叠模式](https://www.w3.org/WAI/ARIA/apg/patterns/disclosure/)

## 分清 Tab 的焦点和选中

切换时，选中标签、显示面板和视觉标记一起更新。在手动激活模式里，方向键可把焦点移到「规格」，当前仍显示「功能」。按 Enter 或 Space 后，规格才被选中。切换按钮则保持名称稳定，例如「仅看有货」，用 `aria-pressed` 表达开关。如果 UI 用复选框实现，浏览器可以提供原生勾选状态。[W3C Tabs](https://www.w3.org/WAI/ARIA/apg/patterns/tabs/) · [切换按钮](https://www.w3.org/WAI/ARIA/apg/patterns/button/)

## 练习与验收

「展开配送说明」和「仅看有货」激活后都变成蓝色。分别选一个状态，在每次操作后检查面板或商品列表、画面及读屏表达是否一致。
