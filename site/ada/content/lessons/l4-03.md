# L4-03 同一张商品图，为什么 alt 会写得不一样？

> **本课目标：** 按用途写替代文本，区分字幕与音频描述的职责。

## 图片在这一处承担什么任务？

德国站商品大图曾被读屏只报成「图形」。给它写替代文本前，先想看不到这张图的用户会漏掉什么。

| 场景 | 要提供的信息 |
| --- | --- |
| 大图展示沿草坪边缘作业 | `alt="Dreame A2 沿草坪边缘割草"`。 |
| 缩略图负责打开大图 | 控件名称说明「查看 A2 沿草坪边缘割草的大图」。 |
| 图和商品标题在同一链接，图只重复商品身份 | 链接使用可见商品标题，图片可用 `alt=""`。 |
| 装饰背景或纹理 | 可使用空替代文本。 |
| 包含关键尺寸的复杂图 | 简要替代文本加可阅读的详细尺寸。 |

```html
<button type="button" aria-label="查看 A2 沿草坪边缘割草的大图">
  <img src="a2-edge-thumbnail.jpg" alt="">
</button>

<img src="a2-edge-large.jpg" alt="Dreame A2 沿草坪边缘割草">
```

前一个是图库的入口，后一个是弹窗里实际要读的大图。Shopify 主题可以由不同模板渲染两者，验收时分别查最终 HTML 和读屏效果。[W3C alt 决策树](https://www.w3.org/WAI/tutorials/images/decision-tree/) · [功能图片](https://www.w3.org/WAI/tutorials/images/functional/)

## 字幕与音频描述

假设产品演示里说「听到提示音后按启动键」，画面才显示启动键位于顶部右侧。字幕将对白与有意义的声音同步显示，例如「［提示音］」。音频描述通过声音补充原音轨没说的关键画面，例如按钮的位置。若旁白已经讲清全部重要视觉信息，可以从现有原声获取这些信息。

德国站曾用带字幕的样本验证播放器控制。对真实视频，要再确认每一条字幕轨可用、语言正确、时间同步，并播放所需音频描述的版本。[WCAG 预录字幕](https://www.w3.org/WAI/WCAG22/Understanding/captions-prerecorded.html) · [预录音频描述](https://www.w3.org/WAI/WCAG22/Understanding/audio-description-prerecorded.html)

## 练习与验收

安装图中有三步操作和一条安全提示，正文只写了「安装很简单」。给图写用途，再决定如何在正文列出完整步骤和安全提示。用读屏依次阅读，并试着回头找到安全提示。
