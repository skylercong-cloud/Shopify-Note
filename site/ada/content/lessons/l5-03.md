# L5-03 结课实战：把商品卡片改到能用键盘和读屏买东西

> **本课目标：** 从代码定位障碍，并用一条购物任务验证修复。

## 结课题：沿购买任务找障碍

下面是假设的商品卡片。鼠标可以加购，成功后只更新页头角标。金额是教学数据。

```html
<div class="product-card">
  <img src="a2-edge.jpg">
  <h2>Dreame A2</h2>
  <p><span class="sale">€899</span> <span class="old">€999</span></p>
  <input type="number" value="1">
  <div class="add-to-cart">加入购物车</div>
</div>
```

模拟读取图、区分价格、改数量、加购、确认结果。给每一步标出用户得到的信息和可以执行的操作。

## 参考实现

```html
<article class="product-card">
  <h2>Dreame A2</h2>
  <img src="a2-edge.jpg" alt="Dreame A2 沿草坪边缘割草">

  <p>促销价 <strong>€899</strong>，原价 <s>€999</s></p>

  <label for="a2-quantity">购买数量</label>
  <input id="a2-quantity" type="number" min="1" step="1" value="1">

  <button type="button" data-add-to-cart>加入购物车</button>
  <p id="a2-cart-status" role="status" aria-atomic="true"></p>
</article>
```

- 图片的 `alt` 传递当前画面的用途。金额旁既有价格，也有「促销价」或「原价」的明确文字。颜色用实际背景测对比度。
- 数量有原生 `label`，加购是可以用键盘激活的原生按钮。接入当前 Shopify 主题原有的商品、变体与数量提交逻辑。
- 实际请求成功后更新状态区，例如「已加入 2 件 Dreame A2」。库存不足时说明可选数量和下一步。卡片可重复渲染时，用实例唯一 ID 关联标签和反馈。

[W3C 图片替代文本](https://www.w3.org/WAI/tutorials/images/decision-tree/) · [表单标签](https://www.w3.org/WAI/tutorials/forms/labels/) · [加购状态消息](https://www.w3.org/WAI/WCAG22/Techniques/aria/ARIA22#examples)

## 练习与验收

| 用户任务 | 要观察的结果 |
| --- | --- |
| 知道图片展示什么 | 读屏能获取沿草坪边缘割草这个信息。 |
| 区分两个金额 | 能确定 €899 为促销价、€999 为原价。 |
| 改数量并加购 | 焦点清晰，使用键盘把数量设为 2 后，实际购物车增加 2 件正确商品。 |
| 获知结果 | 成功时听到正确商品及数量，库存不足时知道如何更正。 |

在窄屏重走任务。若卡片用在 Mall，真机读屏逐项查数量字段及加减按钮。最后换成商品对比页，完成「换一款商品、读续航、打开购买入口」，用三句话写出阻断步骤、修复位置和验收动作。
