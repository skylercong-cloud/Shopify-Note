# L4-02 页面放大后，为什么文字会重叠？

> **本课目标：** 区分文字放大和重排，排查窄屏与短视口的重叠和遮挡。

## 200% 与 320 CSS px

德国站 A2 商品页曾在 320 CSS px 宽度出现文字重叠和浮层遮挡。特别短的视口也可能让滚动展示区内容挤在一起。

| 检查 | 看什么 |
| --- | --- |
| 文字放大到 200% | 标题、文案、标签还能读完整，功能仍可用。 |
| 320 CSS px 等效宽度 | 通常纵向浏览的页面能重新安排内容，用户无需横向来回滚动。 |

1280 CSS px 的视口放到 400%，等效于 320 CSS px 宽度。确实需要二维关系的部分，例如某些数据对比表，可以按准则评估局部滚动例外。[WCAG 调整文本大小](https://www.w3.org/WAI/WCAG22/Understanding/resize-text.html) · [重排](https://www.w3.org/WAI/WCAG22/Understanding/reflow.html)

## 先看正文的空间，再看覆盖层

标题从一行变成三行时，绝对定位的正文可能仍停在原地。固定高度也可能裁掉较长文案。先临时让文字回到文档流、解除固定高度定位，确定原因。图文模块可以让布局随可用空间换行或切换列数：

```css
.product-feature {
  display: grid;
  grid-template-columns: minmax(0, 1fr);
  gap: 1rem;
}

@media (min-width: 48rem) {
  .product-feature {
    grid-template-columns: repeat(2, minmax(0, 1fr));
  }
}
```

若正文可读却被悬浮控件整个盖住，临时隐藏浮层观察，再决定让浮层回到文档流或为固定栏留空间。用 Tab 将焦点带到视口边缘，检查粘性头部和底栏。[WCAG 焦点无遮挡](https://www.w3.org/WAI/WCAG22/Understanding/focus-not-obscured-minimum.html)

## 练习与验收

用一个商品页测试 200% 缩放、320 CSS px 窄屏和横屏短高度。分别确认长文案、价格与购买按钮。若发现覆盖，标出是正文自身重叠、布局溢出，还是浮层遮挡。
