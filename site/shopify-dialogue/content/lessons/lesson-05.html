一、先回答一个最现实的问题

作为前端工程师，你打开一个 Shopify 项目，可能看到：

文本

确实。

React 项目可能是：

文本

├── components/
├── pages/

文本

不要试图把 Shopify 硬套成 React 项目。

五、JSON Template 是什么？

现代 Shopify Theme 中你会大量看到：

文本
product.json

例如：

json
{
  "sections": {
    "main": {
      "type": "main-product"
    },
    "recommendations": {
      "type": "related-products"
    }
  },

  "order": [
    "main",
    "recommendations"
  ]
}

它表达的是：

这个页面由哪些 Section 组成，以及顺序是什么。

例如：

文本
product.json
       │
       ├── main-product
       │
       ├── product-description
       │
       └── related-products

这非常像一个：

页面配置文件。

六、所以 Template 和 Section 是什么关系？

这是非常重要的一层。

文本
Template
   │
   ├── Section
   ├── Section
   └── Section

比如 Product Page：

文本
Product Template
│
├── Main Product
├── Product Description
├── Reviews
└── Related Products

所以：

Template 决定页面由哪些模块组成。

而：

Section 负责具体模块怎么渲染。

九、这里有一个很重要的开发思想

普通 React：

文本
开发者
 ↓
Component
 ↓
Props

Shopify：

文本
开发者
 ↓
Section
 ↓
Schema
 ↓
Theme Editor
 ↓
商家配置
 ↓

所以 Shopify Theme 开发时，你经常不是简单地：

“把 UI 写出来。”

而是在思考：

“这个 UI 哪些东西应该让运营人员自己配置？”

例如：

文本

图片 → image_picker
颜色 → color
商品 → product
商品集合 → collection
链接 → url

十、Snippet：解决重复代码

假设你在很多地方都需要：

文本

价格

你可以创建：

文本
snippets/product-card.liquid

然后：

liquid

这和 React：

jsx

非常类似。

所以：

文本

=

Snippet
=

十一、一个实际例子：商品卡片

假设 Collection 页面有：

文本
┌──────────────┐
│    Image     │
│              │
│ Nike Shoes   │
│ $99.00       │
└──────────────┘

你可能有：

文本
sections/main-collection.liquid

里面循环商品：

liquid
{% for product in collection.products %}

  {% render 'product-card', product: product %}

{% endfor %}

然后：

文本
snippets/product-card.liquid

负责：

liquid
<article class="product-card">

  <img src="{{ product.featured_image | image_url }}">

  <h3>
    {{ product.title }}
  </h3>

  <span>
    {{ product.price | money }}
  </span>

</article>

最终：

文本
Collection Section
        ↓
for products
        ↓
Product Card Snippet
        ↓
HTML

这就是 Shopify Theme 中非常典型的开发模式。

🎯 第 5 课核心知识点

今天你不需要记所有文件。

先把下面这句话记住：

Template 决定页面结构，Section 负责页面模块，Snippet 负责代码复用，Liquid 负责 Shopify 数据渲染，JavaScript 负责浏览器交互。

再加上：

Schema 决定商家在 Theme Editor 里能配置什么。

以及：

Metafield / Metaobject 负责扩展 Shopify 的数据模型。

这几个概念一旦真正掌握，你就已经开始从“前端开发工程师”转换成“Shopify Theme 开发工程师”了。
