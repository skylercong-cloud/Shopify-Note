这是 Shopify Theme 最基础、最原生的方式。

七、Add to Cart 完整代码

我们可以写一个简单版本：

javascript
async function addToCart(variantId, quantity = 1) {

  const response = await fetch('/cart/add.js', {
    method: 'POST',

    headers: {
      'Content-Type': 'application/json'
    },

    body: JSON.stringify({
      items: [
        {
          id: variantId,
          quantity
        }
      ]
    })
  });

  const data = await response.json();

  console.log(data);
}

调用：

javascript
addToCart(102, 1);

就相当于：

文本
Variant 102
Quantity 1
       ↓
Shopify Cart

八、但是实际项目不能这么简单

真实商品页首先要判断：

比如用户只选择了：

那么：

javascript

可能是：

这时候不能加购。

所以：

然后判断库存：

完整一点：

javascript
async function handleAddToCart() {

  if (!variant) {
    alert('Please select an option');
    return;
  }

  if (!variant.available) {
    alert('This variant is sold out');
    return;
  }

  await addToCart(variant.id, 1);
}

十四、所以最简单的完整流程可以这样写

javascript
async function addToCart(variantId, quantity) {

  // 1. 加入购物车
  await fetch('/cart/add.js', {
    method: 'POST',
    headers: {
      'Content-Type': 'application/json'
    },
    body: JSON.stringify({
      items: [
        {
          id: variantId,
          quantity
        }
      ]
    })
  });

  // 2. 获取最新 Cart
  const response = await fetch('/cart.js');

  const cart = await response.json();

  // 3. 更新购物车数量
  updateCartCount(cart.item_count);

  // 4. 打开 Cart Drawer
  openCartDrawer();
}

这就是最基础的：

十六、Section Rendering 的核心思想

假设你的 Theme 有：

文本

里面：

    </div>

  {% endfor %}

那么 Shopify 可以帮你：
