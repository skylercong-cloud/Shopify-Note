好，我们就沿着你刚才的问题，做一个真正的“活动页 → 特殊价格 → 加购 → Cart Drawer → Checkout”实战。

而且我先纠正/补充上一课里一个很重要的点：

八、如果我们使用 Ajax Cart API

那么 JS 可以这样：

js
async function addCampaignProduct(variantId) {
  const response = await fetch(
    window.Shopify.routes.root + 'cart/add.js',
    {
      method: 'POST',

      headers: {
        'Content-Type': 'application/json'
      },

      body: JSON.stringify({
        items: [
          {
            id: variantId,
            quantity: 1,

            properties: {
              "_campaign": "summer_sale"
            }
          }
        ],

        sections: [
          'cart-drawer',
          'cart-icon-bubble'
        ]
      })
    }
  );

  if (!response.ok) {
    throw new Error('Add to cart failed');
  }

  return response.json();
}

这里同时完成了：

文本
① 添加 Variant
② 添加活动上下文
③ 请求 Cart Drawer
④ 请求 Cart Count

Bundled Section Rendering 可以让 Cart API 操作和指定 Sections 的 HTML 渲染在同一次请求里完成；当前文档支持 add/change/clear/update 这些 Cart API endpoint，并最多请求 5 个 sections。Shopify

十、然后进入 Function

这里就是 Theme 和 Shopify Backend 的分界线。

你的 Theme：

文本
“这是 summer_sale”

Function：

文本
“我来判断它是否真的应该获得优惠。”

例如伪代码：

js
function run(input) {
  const operations = [];

  for (const line of input.cart.lines) {

    const campaign =
      getProperty(line, "_campaign");

    const variantId =
      line.merchandise.id;

    if (
      campaign === "summer_sale" &&
      variantId === SUMMER_VARIANT_ID
    ) {

      operations.push({
        productDiscount: {
          targets: [
            {
              cartLine: {
                id: line.id
              }
            }
          ],

          value: {
            fixedAmount: {
              amount: "10.00"
            }
          }
        }
      });
    }
  }

  return {
    operations
  };
}

这只是帮助你理解架构的伪代码，不是可以直接部署的 Function 完整实现。

真正的 Function 会按照 Shopify Functions 的 GraphQL input/output schema 编写。当前 Discount Function 的 cart target 是 cart.lines.discounts.generate.run。Shopify
