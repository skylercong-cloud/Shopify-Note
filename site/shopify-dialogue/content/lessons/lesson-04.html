好，我们进入 第 4 课：Theme、Liquid、JavaScript 到底是怎么运行的。

这一课开始真正进入 Shopify 前端开发。你已经有 2–3 年前端经验，所以我会尽量用你熟悉的 浏览器、SSR、组件、HTTP、JS 来解释，而不是把 Shopify 当成一个完全陌生的体系。

一、先解决一个最核心的问题

你以后开发 Shopify Theme，可能会看到：

文本
Liquid
HTML
CSS
JavaScript
JSON

第一反应可能是：

“这不就是前端吗？”

对，但它和 React/Vue 的运行方式完全不同。

你可以先记住：

文本
React/Vue

服务器
  ↓
API / 数据
  ↓
浏览器
  ↓
React/Vue
  ↓
DOM

而 Shopify Theme 更接近：

文本
Shopify
  ↓
Liquid
  ↓
HTML
  ↓
浏览器
  ↓
JavaScript
  ↓
DOM 交互

也就是说：

Liquid 主要负责“服务器端生成页面”，JavaScript 主要负责“浏览器端交互”。

这是今天最重要的知识。

二、如果你是 React 工程师，可以这样类比

假设我们做一个商品详情页。

React 可能写：

jsx

  return (

      <p>{product.description}</p>
    </div>

这里：

文本

   ↓
React
   ↓
HTML

Shopify Theme 则可能是：

liquid
<div>
  <h1>{{ product.title }}</h1>
  <p>{{ product.description }}</p>
</div>

这里：

文本
Shopify Product
       ↓
Liquid
       ↓
HTML

所以你可以暂时把：

liquid
{{ product.title }}

理解成类似：

jsx
{product.title}

但不要把 Liquid 当成 React。

这是两个完全不同的东西。

三、Liquid 到底是什么？

Liquid 是 Shopify 使用的模板语言。

你可以把它理解成：

“Shopify 服务端模板层”。

最简单的 Liquid：

liquid
<h1>{{ product.title }}</h1>

如果商品叫：

文本
Classic T-Shirt

Shopify 在生成 HTML 时，会把它变成：

html
<h1>Classic T-Shirt</h1>

浏览器最终看到的是：

html
<h1>Classic T-Shirt</h1>

浏览器不知道 Liquid 是什么。

这点非常重要。

四、浏览器不会执行 Liquid

比如你写：

liquid
<h1>{{ product.title }}</h1>

浏览器不会：

文本
解析 Liquid
 ↓
寻找 product
 ↓
读取 title

实际上是：

文本
Shopify Server
     ↓
解析 Liquid
     ↓
生成 HTML
     ↓
发送给浏览器
     ↓
Browser

所以：

文本
Liquid → Server
JavaScript → Browser

这是 Shopify Theme 开发最重要的边界之一。

五、那 JavaScript 干什么？

假设商品页面有：

文本
颜色：
🔴 Red
🔵 Blue

尺码：
S
M
L

用户点击：

文本
Blue

然后页面：

文本
价格
库存
图片
Variant ID

发生变化。

这种浏览器交互一般由 JavaScript 完成。

例如：

javascript
document.querySelectorAll('.color-option')

然后监听：

javascript
button.addEventListener('click', ...)

所以可以简单理解：

文本
Liquid
 ↓
把“初始页面”渲染出来

JavaScript
 ↓
让页面“动起来”

六、一个非常经典的 Shopify 页面

假设：

文本
Product
Title: Classic T-Shirt
Price: $29.99

Liquid：

liquid
<h1>{{ product.title }}</h1>

文本

     ↓
Classic T-Shirt

     ↓

最终浏览器收到类似：

html

  $29.99
</div>

然后 JavaScript 再接管交互。

七、Liquid 的三个核心语法

你现在先掌握三个。

① 输出变量

liquid
{{ product.title }}

意思：

把值输出到 HTML。

例如：

liquid
{{ product.vendor }}

② 条件

liquid
{% if product.available %}
  <button>Add to cart</button>
{% else %}
  <button disabled>Sold out</button>
{% endif %}

这里：

文本
{{ }}

主要用于：

输出数据

而：

文本
{% %}

主要用于：

执行 Liquid 逻辑

③ 循环

例如一个商品有多个 Variant：

liquid
{% for variant in product.variants %}
  <div>
    {{ variant.title }}
  </div>
{% endfor %}

逻辑类似：

javascript
product.variants.forEach(variant => {
  ...
})

但还是那句话：

Liquid 不是 JavaScript。

只是语法上的某些思维方式类似。

八、Filter —— Liquid 一个非常重要的概念

例如：

liquid
{{ product.price | money }}

这里：

文本
product.price
      ↓
    money
      ↓
格式化价格

你可以把：

liquid
{{ value | filter }}

暂时理解成：

javascript
format(value)

例如：

liquid
{{ product.title | upcase }}

可以把文字转换成大写。

还有很多 Filter：

文本
money
upcase
downcase
escape
default
image_url
asset_url
json

以后你会大量使用。

十四、Schema —— Section 为什么能被后台配置？

这就是 Shopify Theme 一个非常关键的设计。

一个 Section 可以定义：

liquid
{% schema %}
{
  "name": "Hero Banner",
  "settings": [
    {
      "type": "text",
      "id": "title",
      "label": "Title"
    }
  ]
}
{% endschema %}

那么 Theme Editor 就可以出现：

文本
Hero Banner

Title:
[ Summer Sale          ]

商家修改：

文本
Summer Sale

Liquid 就可以读取：

liquid
{{ section.settings.title }}

最终：

html
<h1>Summer Sale</h1>

这是 Shopify 前端和普通网站前端一个非常大的区别。

二十、那么 AJAX Cart 是怎么回事？

现在我们进入 Shopify 前端开发非常重要的一部分。

假设用户点击：

文本
Add to Cart

你当然不希望：

文本
点击
 ↓
整个页面刷新
 ↓
Cart 页面

现代 Shopify Theme 通常会通过浏览器 JS 请求 Cart API。

概念上：

文本
User
 ↓
Click Add to Cart
 ↓
JavaScript
 ↓
Shopify Cart API
 ↓
Cart 更新
 ↓
返回 JSON
 ↓
JavaScript 更新 DOM
 ↓
Cart Drawer 打开

例如概念代码：

javascript
fetch('/cart/add.js', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({
    items: [
      {
        id: variantId,
        quantity: 1
      }
    ]
  })
})

注意这里：

文本
variantId

还记得第 3 课吗？

购物车添加的是 Variant，而不是简单的 Product。

这就是为什么第 3 课的数据模型非常重要。
