三、一个非常重要的概念

这里其实有两种 Metafield：

普通业务数据

例如：

文本
Product
└── custom.material

这是我们之前学习的：

liquid
{{ product.metafields.custom.material.value }}

Function Configuration

例如：

文本
Discount
└── function-configuration

它不是简单拿来给 Theme 显示的。

它的目的主要是：

给 Function 提供运行时配置。

Shopify 官方的 Discount Function 示例就是从 discount metafield 中读取 JSON 配置，例如目标 SKU 和折扣百分比。Shopify

四、为什么配置通常是 JSON？

比如：

json
{
  "percentage": 20,
  "skus": [
    "TSHIRT-BLACK",
    "TSHIRT-WHITE"
  ]
}

Function 读取：

graphql
discount {
  metafield(
    namespace: "$app",
    key: "function-configuration"
  ) {
    jsonValue
  }
}

然后 Function：

js
const configuration =
  input.discount?.metafield?.jsonValue ?? {};

得到：

js
{
  percentage: 20,
  skus: [
    "TSHIRT-BLACK",
    "TSHIRT-WHITE"
  ]
}

官方文档现在也推荐复杂 Function 配置使用 JSON metafield，因为活动规则经常是嵌套结构。Shopify

六、把它类比成 React

你作为前端开发，可以这样理解：

传统写法：

js
function Product({ product }) {
  if (product.id === 123) {
    return <SalePrice />;
  }

  return <NormalPrice />;
}

这是：

业务规则硬编码。

配置化：

js
const config = {
  saleProductIds: [123, 456],
  discount: 20
};

然后：

js
function Product({ product, config }) {
  if (config.saleProductIds.includes(product.id)) {
    return <SalePrice />;
  }

  return <NormalPrice />;
}

这就是：

业务逻辑 + 配置分离。

Shopify Functions 也是同样的思想。

八、但 Discount Function 的思路更适合“计算折扣”

这时候出现一个非常重要的设计问题。

原价：

文本

活动价：

文本
$19.99

实际上等价于：

文本

=

=
$10.00

所以 Function 可以计算：

文本

例如：

js

const campaignPrice = 19.99;

const discount = originalPrice - campaignPrice;
// 10.00

然后给 Cart Line：

文本

这样最终：

文本

- $10.00
──────────

九、Function 真正看到什么？

我们可以让 input query 请求：

graphql
query Input {
  cart {
    lines {
      id
      quantity

      merchandise {
        __typename

        ... on ProductVariant {
          id
          product {
            id
          }
        }
      }

      cost {
        amountPerQuantity {
          amount
        }
      }
    }
  }

  discount {
    metafield(
      namespace: "$app",
      key: "function-configuration"
    ) {
      jsonValue
    }
  }
}

于是 Function 拿到：

js
{
  cart: {
    lines: [
      {
        id: "gid://shopify/CartLine/1",

        quantity: 1,

        merchandise: {
          id: "gid://shopify/ProductVariant/123"
        },

        cost: {
          amountPerQuantity: {
            amount: "29.99"
          }
        }
      }
    ]
  },

  discount: {
    metafield: {
      jsonValue: {
        campaign: "summer_sale",
        price: "19.99",
        targetVariantIds: [
          "gid://shopify/ProductVariant/123"
        ]
      }
    }
  }
}

这正是 Shopify 官方 Discount Function 当前支持的模式：Input Query 可以同时读取 Cart Lines 和 discount 上的 metafield 配置。ShopifyShopify

十、然后 Function 做判断

伪代码：

js
for (const line of input.cart.lines) {

  const variantId = line.merchandise.id;

  const isTarget =
    config.targetVariantIds.includes(variantId);

  if (!isTarget) {
    continue;
  }

  const originalPrice =
    Number(line.cost.amountPerQuantity.amount);

  const campaignPrice =
    Number(config.price);

  const discount =
    originalPrice - campaignPrice;

  if (discount <= 0) {
    continue;
  }

  // 创建 discount candidate
}

例如：

文本
Variant
123

原价
29.99

活动价
19.99

↓

Discount
10.00
