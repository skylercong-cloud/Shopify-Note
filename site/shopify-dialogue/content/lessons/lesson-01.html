三、Shopify 到底是什么？

先不要急着学 Liquid。

我们先回答：

Shopify 是什么？

最简单的理解：

Shopify 是一个电商基础设施平台。

假设你自己从 0 做一个电商网站，你需要：

文本
Frontend
Backend
Database
User System
Product System
Order System
Payment
Cart
Checkout
Inventory
Shipping
Email
Admin CMS
Security
Hosting
...

非常麻烦。

Shopify 帮你把这些基础设施都做好了。

所以你可以把 Shopify 想成：

“已经把电商后端做好的一套 SaaS 平台，然后让你通过 Theme / API / App 去定制。”

四、Shopify 开发者到底在开发什么？

这是一个特别重要的问题。

很多刚接触 Shopify 的前端工程师会产生误解：

“Shopify 开发是不是就是写 Liquid？”

不是。

实际上 Shopify 开发大致分成三块。

文本
                 Shopify
                    │
        ┌───────────┼───────────┐
        ↓           ↓           ↓
      Theme        App       Headless
        │           │           │
      Liquid      API        React
      JS/CSS      GraphQL    Hydrogen
        │           │           │
        ↓           ↓           ↓
   商店前台       后台扩展      自定义前台

① Theme Development

主要负责：

消费者看到的 Shopify 商店。

比如：

  • 首页
  • 商品详情页
  • 商品列表
  • Cart
  • Header
  • Footer
  • Search
  • Banner
  • Product Card

这是我们第一阶段重点。

② App Development

主要负责：

给 Shopify 增加 Shopify 本身没有的能力。

例如：

商家安装你的 App：

文本
Shopify Admin
      ↓
你的 App
      ↓
自动给商品添加标签
      ↓
同步 ERP
      ↓
统计销售数据
      ↓
自动化营销

这时候就会大量使用：

文本
GraphQL
API
Webhook
OAuth
App Bridge
Polaris

③ Headless

这个思路更加接近现代前端：

文本

   │

   │
   ↓
React / Next.js / Hydrogen
   │
   ↓
用户浏览器

也就是说：

Shopify 负责电商后端，你自己负责整个前端。

六、第一课：Shopify Theme 到底是什么？

你可以暂时把它理解成：

React 项目

├── pages/

└── ...

只是 Shopify 有自己的目录约定。

七、最重要的 4 个目录

第一阶段你只需要记住：

文本
layout
templates
sections
snippets

其他东西我们后面再学。

1. layout

可以理解成：

整个网站的外壳。

最经典的是：

文本
layout/theme.liquid

你可以把它类比成 React：

jsx
<App>
   <Header />

   <Page />

   <Footer />
</App>

比如：

liquid
<!doctype html>
<html>
<head>
  {{ content_for_header }}
</head>

<body>

  {% section 'header' %}

  {{ content_for_layout }}

  {% section 'footer' %}

</body>
</html>

这里最重要的是：

liquid
{{ content_for_layout }}

它的意思可以简单理解成：

“把当前页面的内容放到这里。”

所以：

文本
theme.liquid
        │
        ├── Header
        │
        ├── content_for_layout
        │          ↓
        │      当前页面
        │
        └── Footer

八、templates 是什么？

如果：

文本
layout = 整个网站的外壳

那么：

文本
template = 某一种页面的结构

例如：

文本
templates/
├── index.json
├── product.json
├── collection.json
├── cart.json
├── page.json
└── search.json

它们分别对应：

文本
index       → 首页
product     → 商品详情
collection  → 商品列表
cart        → 购物车
page        → 普通页面
search      → 搜索

这时候你应该开始发现：

Shopify 的页面结构其实很有规律。

九、sections 是 Shopify Theme 最重要的概念之一

假设你的首页：

文本
Home
│
├── Hero Banner
├── Featured Products
├── Image + Text
├── Testimonials
└── Newsletter

Shopify 可以把它拆成：

文本
sections/
├── hero-banner.liquid
├── featured-products.liquid
├── image-text.liquid
├── testimonials.liquid
└── newsletter.liquid

这和 React Component 的思想非常像：

jsx
<Home>
  <HeroBanner />
  <FeaturedProducts />
  <ImageText />
  <Testimonials />
  <Newsletter />
</Home>

所以：

Section ≈ 一个可以被商家配置/管理的页面组件。

这个概念你一定要记住。

十、Snippets 又是什么？

Snippet 更接近：

可复用的小型代码片段。

例如：

文本
snippets/
├── product-card.liquid
├── price.liquid
├── icon-cart.liquid
└── button.liquid

例如：

liquid
{% render 'product-card', product: product %}

你可以类比：

jsx
<ProductCard product={product} />

所以目前可以先记：

文本
Layout
  ↓
网站外壳

Template
  ↓
页面类型

Section
  ↓
页面模块

Snippet
  ↓
可复用小组件

这四个概念非常重要。

十二、这里出现了一个关键问题

如果你做过 React，你可能马上会问：

“那 Shopify 的 Product 数据从哪里来？”

例如：

liquid
{{ product.title }}

这里的：

文本
product

并不是你自己：

js
fetch('/api/products')

拿到的。

而是 Shopify 在渲染页面的时候，已经提供给 Liquid 的对象。

例如：

liquid
<h1>
  {{ product.title }}
</h1>

如果 Shopify 商品名字是：

文本
Classic Running Shoes

最终 HTML 可能就是：

html
<h1>
  Classic Running Shoes
</h1>

所以：

文本
Shopify 数据
      ↓
Liquid
      ↓
HTML
      ↓
Browser

这就是 Shopify Theme 非常核心的工作方式。

十三、Liquid 是什么？

现在终于可以正式认识 Liquid。

Liquid 是 Shopify 使用的一种：

Server-side template language（服务端模板语言）

你可以把它理解成：

文本
HTML
 +
变量
 +
条件
 +
循环
 +
过滤器
 =
Liquid

例如普通 HTML：

html
<h1>Product Name</h1>

Liquid：

liquid
<h1>{{ product.title }}</h1>

循环：

liquid
{% for product in collection.products %}

  <h2>
    {{ product.title }}
  </h2>

{% endfor %}

你马上应该能看出来：

js
products.map(product => ...)

在 Liquid 里面类似：

liquid
{% for product in products %}

条件：

JavaScript：

js
if (product.available) {
  ...
}

Liquid：

liquid
{% if product.available %}
  Add to Cart
{% endif %}

所以你会发现：

Liquid 本身并不难。

真正需要学习的是：

Shopify 给 Liquid 提供了哪些对象、数据结构和能力。
