这一课我们先解决一个核心问题：

Shopify 的 Collection 页面到底是什么？它和 Product、Product Card、Theme Template、URL 是怎么连接起来的？

你学完之后，应该能自己从零写出一个基础的 Collection 商品列表。

1. 先建立整体模型

假设你的商城有：

文本
/collections/shoes

用户打开这个 URL：

文本
浏览器
   ↓
/collections/shoes
   ↓
Shopify
   ↓
找到 shoes Collection
   ↓
Collection Template
   ↓
Liquid
   ↓
HTML
   ↓
浏览器

所以：

Collection 页面本质上就是“把一个 Collection 对象渲染成一个商品列表页面”。

2. Collection 到底是什么？

假设 Shopify 后台有：

文本
Products

Nike Air Max
Adidas Ultraboost
Nike Pegasus
New Balance 530

然后你创建一个 Collection：

文本
Shoes

里面包含：

文本
Shoes
├── Nike Air Max
├── Adidas Ultraboost
├── Nike Pegasus
└── New Balance 530

所以：

文本
Collection
    ↓
Products

但是要注意：

Collection 不是 Product 的父级。

一个 Product 可以属于多个 Collection。

例如：

文本
Nike Air Max
    │
    ├── Shoes
    ├── Nike
    └── Running

这就是 Shopify 数据模型非常重要的一点。

3. Collection 页面对应哪个对象？

在 Liquid 中：

liquid
{{ collection.title }}

这里的：

文本
collection

就是当前页面对应的 Collection 对象。

比如：

文本
/collections/shoes

Shopify 找到：

文本
Collection:
title = Shoes
handle = shoes

然后 Liquid 就可以访问：

liquid
collection.title
collection.handle
collection.products
collection.description

4. 最重要的：collection.products

Collection 页面最核心的东西：

liquid
collection.products

它代表：

当前 Collection 中的 Product 列表。

例如：

liquid
{% for product in collection.products %}
  <h2>{{ product.title }}</h2>
{% endfor %}

假设 Collection 里面有：

文本
Nike Air Max
Adidas Ultraboost
Nike Pegasus

最终 HTML 大概就是：

html
<h2>Nike Air Max</h2>
<h2>Adidas Ultraboost</h2>
<h2>Nike Pegasus</h2>

5. 这和 React 很像

你作为前端开发应该很好理解。

React：

jsx
function CollectionPage({ collection }) {
  return (
    <div>
      <h1>{collection.title}</h1>

      {collection.products.map(product => (
        <ProductCard
          key={product.id}
          product={product}
        />
      ))}
    </div>
  );
}

Shopify Liquid：

liquid
<h1>{{ collection.title }}</h1>

{% for product in collection.products %}
  {% render 'product-card', product: product %}
{% endfor %}

可以直接建立这个对应关系：

文本
React                     Shopify

props.collection    →     collection
array.map()         →     for
ProductCard         →     snippet
product.title       →     product.title
component           →     snippet

6. Product Card

实际项目中，我们不会直接把商品 HTML 全写在 Collection 页面。

通常会拆成：

文本
sections/
    main-collection-product-grid.liquid

snippets/
    product-card.liquid

Collection：

liquid
{% for product in collection.products %}
  {% render 'product-card', product: product %}
{% endfor %}

Product Card：

liquid
<div class="product-card">

  {% if product.featured_image %}
    <img
      src="{{ product.featured_image | image_url: width: 500 }}"
      alt="{{ product.title | escape }}"
    >
  {% endif %}

  <h3>
    {{ product.title }}
  </h3>

  <p>
    {{ product.price | money }}
  </p>

</div>

这就和 React：

文本
CollectionPage
    ↓
ProductCard

非常像。

7. 一个完整的 Collection Section

我们先写一个最基础版本。

liquid
<section class="collection">

  <header class="collection-header">

    <h1>
      {{ collection.title }}
    </h1>

    {% if collection.description != blank %}
      <div class="collection-description">
        {{ collection.description }}
      </div>
    {% endif %}

  </header>


  <div class="product-grid">

    {% for product in collection.products %}

      {% render 'product-card', product: product %}

    {% else %}

      <p>No products found.</p>

    {% endfor %}

  </div>

</section>

这里出现了一个非常值得注意的语法：

liquid
{% for product in collection.products %}

后面可以接：

liquid
{% else %}

也就是说：

文本
有商品
 ↓
for

没有商品
 ↓
else

9. Collection URL

例如：

文本
/collections/shoes

这个：

文本
shoes

就是 Collection 的 handle。

所以：

liquid
{{ collection.handle }}

得到：

文本
shoes

而：

liquid
{{ collection.url }}

可以得到：

文本
/collections/shoes

10. Collection 和 Template 的关系

这是 Shopify Theme 结构里面非常重要的一层。

例如：

文本
templates/
    collection.json

这个 Template 负责：

Collection 页面整体由哪些 Section 组成。

例如：

json
{
  "sections": {
    "main": {
      "type": "main-collection-product-grid"
    }
  },
  "order": [
    "main"
  ]
}

然后：

文本
/collections/shoes
        ↓
collection.json
        ↓
main-collection-product-grid
        ↓
collection
        ↓
collection.products
        ↓
Product Card

你应该把这条链记住。

11. Template 和 Section 再理解一次

用 React 类比：

文本
collection.json
        ↓
页面结构 / 页面配置
        ↓
Section
        ↓
Component
        ↓
Snippet

更准确地说：

文本
collection.json
    ↓
Section composition
    ↓
main-collection-product-grid.liquid
    ↓
product-card.liquid

所以：

Template 决定页面由哪些 Section 组成。

Section 负责页面模块。

Snippet 负责复用的小组件。

12. 为什么 Shopify 要这么设计？

因为商家可以在 Theme Editor 中调整：

文本
Collection Page

┌────────────────────────────┐
│ Collection Banner          │
├────────────────────────────┤
│ Collection Description     │
├────────────────────────────┤
│ Filter                     │
├────────────────────────────┤
│ Product Grid               │
└────────────────────────────┘

而开发者可以把它们拆成：

文本
sections/
├── collection-banner.liquid
├── collection-description.liquid
├── collection-filters.liquid
└── main-collection-product-grid.liquid

这就是 Shopify Theme 的模块化思想。

13. Product Grid

现在我们真正做一个商品网格：

liquid
<div class="product-grid">

  {% for product in collection.products %}

    <article class="product-card">

      <a href="{{ product.url }}">

        {% if product.featured_image %}
          <img
            src="{{ product.featured_image | image_url: width: 500 }}"
            alt="{{ product.title | escape }}"
          >
        {% endif %}

        <h2>
          {{ product.title }}
        </h2>

        <span>
          {{ product.price | money }}
        </span>

      </a>

    </article>

  {% endfor %}

</div>

浏览器最终看到的就是：

文本
┌────────────┐ ┌────────────┐ ┌────────────┐
│   IMAGE    │ │   IMAGE    │ │   IMAGE    │
│            │ │            │ │            │
│ Nike Air   │ │ Adidas     │ │ Nike       │
│ $99        │ │ $120       │ │ $89        │
└────────────┘ └────────────┘ └────────────┘

14. 但是这里有一个问题

假设 Collection 有：

文本
500 个商品

你不能：

liquid
{% for product in collection.products %}

然后一次性全部渲染。

否则：

文本
500 Products
    ↓
500 Product Cards
    ↓
大量 HTML
    ↓
页面性能下降

所以 Shopify 有：

Pagination

例如：

文本
Collection
   ↓
Products
   ↓
Pagination
   ↓
Page 1

15. Shopify Pagination

典型写法：

liquid
{% paginate collection.products by 24 %}

  <div class="product-grid">

    {% for product in collection.products %}

      {% render 'product-card', product: product %}

    {% endfor %}

  </div>

  {{ paginate | default_pagination }}

{% endpaginate %}

意思是：

文本
collection.products
        ↓
每页 24 个
        ↓
Page 1
Page 2
Page 3
...

例如：

文本
?page=2

Shopify 会处理对应页面的数据。

16. 这时候你应该看到一个非常重要的关系

文本
URL
 ↓
Collection
 ↓
Pagination
 ↓
Products
 ↓
Product Card

比如：

文本
/collections/shoes?page=2

可以理解成：

文本
Collection = shoes
Page       = 2
Products   = 第 2 页商品

这就是 Shopify Theme 非常典型的：

URL 驱动页面状态

17. 再加入排序

Collection 页面经常有：

文本

Featured
Price: Low to High
Price: High to Low
Best Selling
Newest

URL 可能变成：

文本
/collections/shoes?sort_by=price-ascending

所以整个页面实际上受到：

文本
Collection
+
page
+
sort_by
+
filters

影响。

最终我们会得到：

文本
/collections/shoes
        │
        ├── ?page=2
        │
        ├── ?sort_by=price-ascending
        │
        └── ?filter...

后面我们讲 Filtering 时会把这部分彻底串起来。

19. 和 React 再做一次映射

你可以把整个 Collection 页面想成：

jsx
function CollectionPage({ collection, searchParams }) {
  const products = collection.products;

  return (
    <CollectionLayout>

      <CollectionHeader
        title={collection.title}
        description={collection.description}
      />

      <ProductGrid>
        {products.map(product => (
          <ProductCard
            key={product.id}
            product={product}
          />
        ))}
      </ProductGrid>

    </CollectionLayout>
  );
}

而 Shopify：

liquid
<h1>{{ collection.title }}</h1>
