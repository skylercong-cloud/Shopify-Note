# 第 8 课：Add to Cart 实战

这一课我们把上一课的 **Variant Selector** 真正接到 Shopify Cart 上。

今天你要掌握的核心链路是：

```text
用户选择 Color / Size
        ↓
找到 Variant
        ↓
拿到 Variant ID
        ↓
Add to Cart
        ↓
Shopify Cart
        ↓
更新页面购物车状态
```

这一课学完，你就能真正理解 Shopify 商品页的“加购”是怎么工作的。

---

# 一、先把上一课接起来

上一课我们得到：

```javascript
const variant = variants.find(...)
```

例如用户选择：

```text
Color: Black
Size: M
```

找到：

```javascript
{
  id: 102,
  title: "Black / M",
  price: 2999,
  available: true
}
```

那么：

```javascript
variant.id
```

就是：

```text
102
```

现在我们要做的事情非常简单：

> 把 `102` 告诉 Shopify。

也就是：

```text
Variant ID
   ↓
Shopify Cart
```

---

# 二、第一种方式：Product Form

这是 Shopify Theme 最基础、最原生的方式。

我们可以：

```liquid
{% form 'product', product %}

  <select name="id">
    {% for variant in product.variants %}
      <option value="{{ variant.id }}">
        {{ variant.title }}
      </option>
    {% endfor %}
  </select>

  <input
    type="number"
    name="quantity"
    value="1"
    min="1"
  >

  <button type="submit">
    Add to Cart
  </button>

{% endform %}
```

注意这里：

```html
name="id"
```

对应的是：

> Variant ID

比如：

```html
<option value="102">
  Black / M
</option>
```

用户提交 Form 后：

```text
Variant ID = 102
Quantity = 1
```

Shopify 就知道：

> 我要把 Variant 102 加入 Cart。

---

# 三、为什么 Product Form 很重要？

因为 Shopify 已经帮你定义了标准的商品加购机制。

你不需要自己设计：

```text
POST 什么 URL？
参数叫什么？
Variant ID 放哪里？
```

Shopify Form 已经有约定。

你只需要：

```text
name="id"
```

告诉 Shopify：

> 我要买哪个 Variant。

以及：

```text
name="quantity"
```

告诉 Shopify：

> 我要买几个。

---

# 四、如果用户选择 Color + Size 怎么办？

这时候就不能简单地：

```html
<select name="id">
```

因为真实商品通常是：

```text
Color
Size
```

用户可能选择：

```text
Black
M
```

我们需要：

```text
Black + M
       ↓
Variant
       ↓
ID = 102
```

所以常见实现方式是：

```text
用户选择
   ↓
JavaScript 匹配 Variant
   ↓
更新 Product Form 中隐藏的 Variant ID
```

例如：

```html
<input
  type="hidden"
  name="id"
  value="102"
>
```

这时候 Product Form 实际提交的是：

```text
id = 102
quantity = 1
```

这就是一个非常重要的 Shopify Theme 模式：

```text
Variant Selector
       ↓
JavaScript
       ↓
<input name="id">
       ↓
Product Form
       ↓
Cart
```

---

# 五、第二种方式：Ajax Cart API

如果你想要现代电商常见的：

> 点击 Add to Cart 后页面不刷新。

那么通常会用 Ajax Cart API。

核心接口：

```text
/cart/add.js
```

例如：

```javascript
fetch('/cart/add.js', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({
    items: [
      {
        id: 102,
        quantity: 1
      }
    ]
  })
});
```

这句话可以翻译成人话：

```text
把 Variant 102
数量 1
加入当前 Cart
```

---

# 六、为什么是 `items`？

因为一次可以添加多个商品。

例如：

```javascript
{
  items: [
    {
      id: 102,
      quantity: 1
    },
    {
      id: 205,
      quantity: 2
    }
  ]
}
```

意思：

```text
Black / M × 1
Jeans / 32 × 2
```

所以 Cart 最终可能是：

```text
Cart
├── T-Shirt × 1
└── Jeans × 2
```

---

# 七、Add to Cart 完整代码

我们可以写一个简单版本：

```javascript
async function addToCart(variantId, quantity = 1) {

  const response = await fetch('/cart/add.js', {
    method: 'POST',

    headers: {
      'Content-Type': 'application/json'
    },

    body: JSON.stringify({
      items: [
        {
          id: variantId,
          quantity
        }
      ]
    })
  });

  const data = await response.json();

  console.log(data);
}
```

调用：

```javascript
addToCart(102, 1);
```

就相当于：

```text
Variant 102
Quantity 1
       ↓
Shopify Cart
```

---

# 八、但是实际项目不能这么简单

真实商品页首先要判断：

```javascript
variant
```

是否存在。

比如用户只选择了：

```text
Color = Black
Size = null
```

那么：

```javascript
variant
```

可能是：

```text
undefined
```

这时候不能加购。

所以：

```javascript
if (!variant) {
  return;
}
```

然后判断库存：

```javascript
if (!variant.available) {
  return;
}
```

完整一点：

```javascript
async function handleAddToCart() {

  if (!variant) {
    alert('Please select an option');
    return;
  }

  if (!variant.available) {
    alert('This variant is sold out');
    return;
  }

  await addToCart(variant.id, 1);
}
```

---

# 九、这里就出现了一个很重要的前端状态

商品页实际上有：

```text
selectedOptions
```

和：

```text
selectedVariant
```

例如：

```javascript
const state = {
  selectedOptions: {
    Color: 'Black',
    Size: 'M'
  },

  selectedVariant: {
    id: 102,
    price: 2999,
    available: true
  },

  quantity: 1
};
```

如果用 React 思维：

```text
State
├── selectedOptions
├── selectedVariant
└── quantity
```

Shopify Theme 没有 React State，但你完全可以用 JavaScript 管理类似的状态。

# 十、点击 Add to Cart 后，真正发生了什么？

完整流程：

```text
用户点击 Add to Cart
        ↓
JavaScript
        ↓
检查 selectedVariant
        ↓
检查 available
        ↓
获取 variant.id
        ↓
POST /cart/add.js
        ↓
Shopify Cart
        ↓
返回结果
```

比如：

```javascript
const response = await fetch('/cart/add.js', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({
    items: [
      {
        id: selectedVariant.id,
        quantity: quantity
      }
    ]
  })
});

const data = await response.json();
```

---

# 十一、Shopify 返回什么？

它会返回刚刚加入 Cart 的相关数据。

你可以：

```javascript
console.log(data);
```

然后拿到对应的 Cart Line Item 信息。

你可以把它理解成：

```text
Request

Variant 102
Quantity 1

        ↓

Shopify

        ↓

Response

{
  item: {
    ...
  }
}
```

具体字段以 Shopify Ajax API 当前返回结构为准。

如果我们只是：

所以实际 Theme 还需要：

```text

```

这就是我们上一课说的：

> **Cart API 负责数据，Cart Drawer 负责体验。**

# 十三、那么怎么更新购物车数量？

可以调用：

```text
/cart.js
```

获取当前 Cart。

例如：

```javascript
const response = await fetch('/cart.js');

const cart = await response.json();

console.log(cart);
```

你可以拿到：

```text
Cart
├── items
├── item_count
├── total_price
└── ...
```

于是：

```javascript
cart.item_count
```

可以用来更新：

```text
购物车图标：

🛒 3
```

# 十四、所以最简单的完整流程可以这样写

```javascript
async function addToCart(variantId, quantity) {

  // 1. 加入购物车
  await fetch('/cart/add.js', {
    method: 'POST',
    headers: {
      'Content-Type': 'application/json'
    },
    body: JSON.stringify({
      items: [
        {
          id: variantId,
          quantity
        }
      ]
    })
  });

  // 2. 获取最新 Cart
  const response = await fetch('/cart.js');

  const cart = await response.json();

  // 3. 更新购物车数量
  updateCartCount(cart.item_count);

  // 4. 打开 Cart Drawer
  openCartDrawer();
}
```

这就是最基础的：

```text
Add → Get Cart → Update UI
```

# 十五、但 Shopify Theme 有更好的方案

你可能马上发现：

```text
/cart/add.js
       ↓
/cart.js
```

这样我们调用了两次 API。

而且：

```text
/cart.js
```

返回的是 JSON。

我们还需要自己：

```text
JSON
 ↓
DOM
```

去更新 UI。

这时候就轮到我们上一课提到的：

# Section Rendering API

# 十六、Section Rendering 的核心思想

假设你的 Theme 有：

```text
sections/cart-drawer.liquid
```

里面：

```liquid
<div class="cart-drawer">

  {% for item in cart.items %}

    <div class="cart-item">
      {{ item.product.title }}
      {{ item.quantity }}
    </div>

  {% endfor %}

  <div>
    {{ cart.total_price | money }}
  </div>

</div>
```

那么 Shopify 可以帮你：

> 根据最新 Cart 重新执行这个 Liquid Section。

于是：

```text
Cart API
   ↓
Shopify
   ↓
重新渲染 cart-drawer.liquid
   ↓
返回 HTML
```

你不用自己把整个 Cart HTML 拼出来。

---

# 十七、这就是 Shopify Theme 很有特色的地方

React 的思维可能是：

```text
API
 ↓
JSON
 ↓
setState()
 ↓
React Re-render
```

Shopify Theme 可以是：

```text
Cart API
 ↓
Shopify
 ↓
Liquid Section Render
 ↓
HTML
 ↓
替换 DOM
```

两者思想非常接近：

```text
数据发生变化
      ↓
UI 重新渲染
```

只是渲染的位置不同。

# 十九、一个非常重要的概念：Cart Line Item

现在我们再深入一点。

假设：

```text
Product:
T-Shirt

Variant:
Black / M
```

加入 Cart 后：

```text
Cart
└── Line Item
      ├── Variant
      ├── Quantity
      ├── Price
      └── Properties
```

注意：

> **Cart 里面实际存的是 Line Items。**

例如：

```text
Cart
├── T-Shirt / Black / M × 1
├── Jeans / Blue / 32 × 2
└── Hat / Black × 1
```

每一行就是一个：

```text
Cart Line Item
```

这为下一节：

```text
数量 + / -
删除商品
```

做准备。

# 二十、还有一个非常重要的东西：Line Item Properties

这是 Shopify Theme 很常用的功能。

例如用户购买：

```text
定制 T-Shirt
```

还可以输入：

```text
姓名：
Skyler

定制文字：
HELLO
```

这些不是 Variant。

而是：

> **Line Item Properties**

Product Form 可以提交类似：

```html
<input
  type="text"
  name="properties[Name]"
>
```

以及：

```html
<input
  type="text"
  name="properties[Custom Text]"
>
```

最终 Cart Line Item 可以带：

```text
T-Shirt
Black / M

Name: Skyler
Custom Text: HELLO
```

这在：

- 定制商品
- 礼物留言
- 雕刻文字
- 上传定制信息

等场景非常常见。

# 二十一、现在你应该区分 3 个东西

这是非常容易混淆的：

### Variant

决定：

```text
我买的是哪一个 SKU？
```

例如：

```text
Black / M
```

---

### Quantity

决定：

```text
我要几个？
```

例如：

```text
3
```

---

### Line Item Properties

决定：

```text
这个商品有没有额外定制信息？
```

例如：

```text
Name = Skyler
Message = Happy Birthday
```

最终：

```text
Line Item
├── Variant: Black / M
├── Quantity: 3
└── Properties
    ├── Name: Skyler
    └── Message: Happy Birthday
```

这个数据结构你以后会经常遇到。

# 二十二、这一课你真正需要掌握的 API

目前先记这几个：

```text
POST /cart/add.js
```

加入商品。

```text
GET /cart.js
```

获取当前 Cart。

后面我们会继续学：

```text
POST /cart/change.js
```

修改某个 Cart Item。

以及：

```text
POST /cart/update.js
```

更新 Cart。

还有：

```text
POST /cart/clear.js
```

清空 Cart。

这些共同组成 Shopify Ajax Cart API。 [Cart API reference](https://shopify.dev/docs/api/ajax/reference/cart)
