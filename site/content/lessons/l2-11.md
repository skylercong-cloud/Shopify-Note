# L2-11 Search：完整搜索页面

> **本课目标：** 把搜索词、结果类型和分页表达在 URL 中。

官方参考：

- [Storefront search](https://shopify.dev/docs/storefronts/themes/navigation-search/search)
- [Liquid `search`](https://shopify.dev/docs/api/liquid/objects/search)

## 搜索 URL 本身就是状态

用户搜索：

```text
shirt
```

典型 URL：

```text
/search?q=shirt
```

所以你不需要在浏览器自己维护：

```js
state.searchQuery = 'shirt'
```

才能让页面可恢复。

URL 已经是：

```text
可分享
可刷新
可返回
可被服务器解析
```

的状态容器。

---

## `search.results` 不一定都是 Product

这一点很容易被电商直觉误导。

Search 可能返回：

```text
Product
Page
Article
```

所以：

```liquid
{% for item in search.results %}
  {% case item.object_type %}
    {% when 'product' %}
      ...
    {% when 'article' %}
      ...
    {% when 'page' %}
      ...
  {% endcase %}
{% endfor %}
```

不要：

```liquid
{{ item.price }}
```

默认所有结果都有价格。

## Search Page 的最小结构

```liquid
<form action="{{ routes.search_url }}" method="get" role="search">
  <input
    type="search"
    name="q"
    value="{{ search.terms | escape }}"
  >
  <button type="submit">Search</button>
</form>

{% if search.performed %}
  <p>{{ search.results_count }} results</p>

  {% paginate search.results by 24 %}
    {% for item in search.results %}
      ...
    {% endfor %}
  {% endpaginate %}
{% endif %}
```

这里：

```text
GET form
↓
URL q=...
↓
Shopify Search
↓
Liquid search object
```
