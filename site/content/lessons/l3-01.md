# L3-01 Product / Variant 的身份与关系

> **本课目标：** 区分 Product ID、Variant ID 和 SKU。

官方参考：

- [Liquid `product`](https://shopify.dev/docs/api/liquid/objects/product)
- [Liquid `variant`](https://shopify.dev/docs/api/liquid/objects/variant)

## Product 回答“卖的是什么”

例如：

```text
Classic T-Shirt
```

它承载：

```text
title
handle
description
vendor
product type
options
variants
media
collections
metafields
```

---

## Variant 回答“实际买的是哪个规格”

```text
Classic T-Shirt
+ Black
+ M
= Black / M Variant
```

这个 Variant 才有独立：

```text
ID
SKU
price
barcode
availability
```

所以购买链路：

```text
Product
↓
Option Values
↓
Variant
↓
Variant ID
↓
Cart
```

---

## Product ID、Variant ID、SKU 为什么都不能混？

| 标识 | 谁生成/维护 | 主要用途 |
|---|---|---|
| Product ID | Shopify | API / 资源关系 |
| Variant ID | Shopify | SKU 级 API / Cart |
| SKU | 商家业务字段 | ERP / WMS / PIM 对接 |
| Handle | Shopify/商家可调整 | URL |

所以：

```text
SKU ≠ Variant ID
Handle ≠ Product ID
```
