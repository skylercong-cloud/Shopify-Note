# L3-04 Cart / Checkout / Order 生命周期

> **本课目标：** 理解购买意图、交易确认和购买结果。

官方参考：

- [Storefront Cart](https://shopify.dev/docs/api/storefront/latest/objects/Cart)
- [Admin GraphQL Order](https://shopify.dev/docs/api/admin-graphql/latest/objects/Order)

## Cart 是购买意图

```text
用户准备买：
Black / M × 2
Socks × 1
```

还不等于交易完成。

用户可以：

```text
关掉网页
```

Cart 曾经存在，但没有 Order。

---

## Checkout 是交易确认过程

它进一步处理：

```text
shipping address
shipping rate
tax
discount
payment
final total
```

所以 Cart 中看到的金额，不能简单认为一定和最终 Order 完全相同。

---

## Order 是购买结果

当购买流程完成后，才进入：

```text
Order
```

Order 后面再连接：

```text
Transaction
Fulfillment
Refund
Return
```

---

## Cart Line 和 Order Line Item 为什么不能认为是同一个对象？

```text
Cart Line
→ 购买过程中
```

```text
Order Line Item
→ 成交记录中
```

Order 需要保存成交当时的快照语义。

如果 Product 第二天改名/改价：

```text
历史 Order
```

不能因此失去原成交信息。
