# Shopify Resources

## Knowledge

- [Shopify Theme architecture](https://shopify.dev/docs/storefronts/themes/architecture)
  官方主题目录与渲染组成说明；用于理解 layout、templates、sections、snippets、assets 和 config 的职责。
- [Templates](https://shopify.dev/docs/storefronts/themes/architecture/templates)
  官方模板模型，重点解释 JSON 模板与 Liquid 模板的选择。
- [JSON templates](https://shopify.dev/docs/storefronts/themes/architecture/templates/json-templates)
  官方 JSON 模板格式、sections/order、Theme Editor 可配置能力和限制。
- [Sections](https://shopify.dev/docs/storefronts/themes/architecture/sections)
  官方 Section、Block、动态添加和静态渲染说明。
- [Section schema](https://shopify.dev/docs/storefronts/themes/architecture/sections/section-schema)
  官方 schema 设置类型、presets、blocks 与 enabled_on/disabled_on。
- [Shopify CLI for themes](https://shopify.dev/docs/storefronts/themes/tools/cli)
  官方 CLI 开发流程、development theme、热更新和 Theme Check。
- [Liquid reference](https://shopify.dev/docs/api/liquid)
  官方 Liquid 对象、标签、过滤器和主题运行时参考。

## Wisdom

- [Shopify Community](https://community.shopify.dev/)
  官方开发者社区；用于查找真实主题开发问题和版本变化。
